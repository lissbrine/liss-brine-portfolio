# Liss Brine – Personal Portfolio

Welcome to my personal portfolio website!

This project represents my journey into web development, artificial intelligence, and software engineering.

## About the Project

The Liss Brine Portfolio is a personal website designed to introduce me, showcase my developing technical skills, and provide information about my projects.

## Built With

- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Interactive website features

## Features

- Personal introduction section
- About Me section
- Skills section
- Projects section
- Contact section
- Interactive Discover More button
- Responsive layout for mobile devices
- Dark theme with purple accents

## JavaScript Functionality

The Discover More button uses JavaScript event listeners to:

- Change the welcome message when clicked.
- Reveal the About Me section.
